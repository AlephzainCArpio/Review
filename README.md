## Topics Covered

### ✅ Fundamentals
- Variables (`let`, `const`, `var`)
- Data types (strings, numbers, booleans)
- Conditionals (`if`, `else if`, `else`)
- Loops (`for`, `forEach`)
- Hoisting (var vs let/const, declarations vs expressions)
- Closures (lexical scope, factory functions, stateful functions)

### ✅ Functions
- Declarations vs expressions
- Arrow functions
- Parameters, arguments, return values
- Higher-order functions

### ✅ Arrays
- Indexing, `.length`, mutation
- `map`, `filter`, `reduce`
- Method chaining

### ✅ Objects
- Key-value pairs, dot notation
- Methods with `this`
- Arrays of objects
- Destructuring

### ✅ ES6+ Features
- Template literals
- Destructuring
- Spread and rest operators (`...`)
- Arrow functions

### ✅ Error Handling
- `try`, `catch`, `throw`
- Input validation
- Custom error messages

### ✅ Asynchronous JavaScript
- Promises (`resolve`, `reject`, `.then()`, `.catch()`)
- `async` / `await`

### ✅ DOM Manipulation
- Selecting elements (`getElementById`)
- `textContent`, `input.value`
- `addEventListener`
- Interactive UI (counter, input, button events)

### ✅ Version Control
- Git branch workflow
- Staging, committing, pushing
- Pull requests

### ✅ `this` Keyword
- `this` in global scope
- `this` in regular functions vs methods
- `this` in arrow functions (no own `this`)
- Arrow functions inside methods (inheriting `this`)
- Losing context when detaching a method
- Fixing lost context with `.bind()`

### ✅ Classes
- Class declaration and constructor
- Adding methods to a class
- Inheritance with `extends`
- `super` keyword
- Static methods

### ✅ Callbacks
- Passing functions as arguments
- Callbacks with data
- Callbacks in array methods (forEach, map)
- Async callbacks with setTimeout
- Error-first callback pattern (Node.js style)
- Callback hell and why promises exist

### ✅ JSON
- JSON syntax and rules
- JSON.stringify() — object to string
- JSON.parse() — string to object
- JSON vs JavaScript objects
- Pretty printing with JSON.stringify
- Fetching and parsing API data

### ✅ HTML + CSS
- Semantic HTML tags — header, nav, main, section, article, footer
- CSS Box Model — margin, padding, border, box-sizing
- Flexbox — display: flex, justify-content, align-items, gap
- CSS Grid — grid-template-columns, repeat(), 1fr, gap
- Responsive Design — media queries, mobile-first breakpoints
- HTML Forms — input, label, button, form structure + CSS styling

### ✅ React
- Components — function components, JSX syntax
- Props — passing and receiving data between components
- useState — managing and updating component state
- Event Handling — onClick, onChange
- List Rendering — .map() with unique keys
- Conditional Rendering — toggling content with state
